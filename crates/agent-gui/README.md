# ReactorPro

A desktop Agent client built with Tauri + React, supporting text mode, tool mode, MCP integration and progressive disclosure of Skills within the working directory.

## Development

- Frontend dev: `pnpm dev`
- Desktop dev: `pnpm tauri dev`
- Frontend build: `pnpm build`
- The Windows platform automatically merges `src-tauri/tauri.windows.conf.json`
- The macOS platform automatically merges `src-tauri/tauri.macos.conf.json`
